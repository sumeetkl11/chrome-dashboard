# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2024-11-20

### Added
- 🎉 Complete rewrite with modular architecture
- ✨ IndexedDB for offline-first storage
- 🔍 Fuzzy search with Fuse.js
- 🎨 Glassmorphic UI design with smooth animations
- ♿ Full WCAG AAA accessibility compliance
- 📊 Link analytics and click tracking
- 🌓 Theme system with light/dark modes and auto-detection
- 🔒 Enhanced security with input sanitization
- 📱 Improved mobile responsive design
- ⚡ Performance optimizations (lazy loading, debouncing)
- 🎯 Spring physics animation system
- 🎨 Gesture feedback (ripples, confetti, shake effects)
- ⌨️ Full keyboard navigation support
- 🌐 Multiple dashboard layouts (index, enhanced, ultra, dashboard)

### Changed
- Migrated from localStorage to IndexedDB
- Improved GitHub Gist sync reliability
- Enhanced URL validation and sanitization
- Better error handling and user feedback
- Modernized CSS with custom properties
- Updated dependencies to latest versions

### Fixed
- Search performance with large datasets
- Theme switching reliability
- Mobile gesture conflicts
- Accessibility issues with screen readers
- Focus management in modals

## [1.0.0] - 2024-08-20

### Added
- Initial release
- Basic folder and link management
- GitHub Gist sync functionality
- Dark theme support
- Basic Chrome extension functionality

## Versioning Guide

- **MAJOR** version when you make incompatible API changes
- **MINOR** version when you add functionality in a backward compatible manner
- **PATCH** version when you make backward compatible bug fixes

## Types of Changes
- `Added` for new features
- `Changed` for changes in existing functionality
- `Deprecated` for soon-to-be removed features
- `Removed` for now removed features
- `Fixed` for any bug fixes
- `Security` for vulnerability fixes
